# Datos - Semana 2

El notebook utiliza `sklearn.datasets.fetch_california_housing(as_frame=True)`.

El conjunto California Housing contiene 20.640 observaciones, ocho variables predictoras numéricas y una variable objetivo continua `MedHouseVal`.

Variables predictoras:

- `MedInc`
- `HouseAge`
- `AveRooms`
- `AveBedrms`
- `Population`
- `AveOccup`
- `Latitude`
- `Longitude`

La carga estándar utilizada no presenta valores faltantes. La primera ejecución puede requerir acceso a Internet si el dataset no está disponible en la caché local de scikit-learn.
