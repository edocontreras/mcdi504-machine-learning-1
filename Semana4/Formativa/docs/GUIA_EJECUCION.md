# Guía de ejecución · Formativa 4

1. Clonar o descargar el repositorio completo.
2. Crear/activar un entorno Python compatible.
3. Instalar dependencias desde la raíz: `python -m pip install -r requirements.txt`.
4. Iniciar Jupyter y abrir `Semana4/Formativa/notebook/F4_Evaluacion.ipynb`.
5. Ejecutar `Restart Kernel and Run All Cells`.
6. Verificar al final los mensajes:
   - `Control final de consistencia: OK`
   - `Validación cruzada MLP 1 capa: OK`
   - `Artefactos requeridos: OK`
7. Confirmar la creación de `outputs/` y `figures/`.

El notebook localiza la raíz del repositorio y reutiliza `Semana3/data/titanic.csv`. No debe ejecutarse como archivo aislado fuera de la estructura del proyecto.
