# Reproducción de la corrida de Semana 4

1. Crear o activar un entorno compatible con `requirements.txt`.
2. Desde la raíz del repositorio ejecutar:
   ```bash
   python -m pip install -r requirements.txt
   jupyter notebook
   ```
3. Abrir `Semana4/notebook/F4_Evaluacion.ipynb`.
4. Reiniciar el kernel.
5. Ejecutar todas las celdas en orden.
6. Confirmar que no exista ninguna celda con error.
7. Confirmar que la última celda indique:
   ```text
   Control final de consistencia: OK
   Continuidad con Semana 3: OK
   Artefactos requeridos: OK
   ```
8. Guardar el notebook después de la ejecución.

El notebook regenera los artefactos analíticos de `Semana4/data/`, `Semana4/outputs/` y `Semana4/figures/`. No modifica las evidencias históricas de Semanas 1-3 ni los documentos finales de `Semana4/docs/` e `Semana4/informe/`.
