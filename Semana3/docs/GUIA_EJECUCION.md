# Reproducción de la corrida

1. Crear o activar un entorno compatible con `requirements.txt`.
2. Desde la raíz del repositorio ejecutar:
   ```bash
   python -m pip install -r requirements.txt
   jupyter notebook
   ```
3. Abrir `Semana3/notebook/F3_RedesNeuronales.ipynb`.
4. Reiniciar el kernel.
5. Ejecutar todas las celdas en orden.
6. Confirmar que no exista ninguna celda con error.
7. Confirmar que la última celda indique `Validación de artefactos: OK`.
8. Guardar el notebook después de la ejecución.

El notebook elimina y regenera únicamente los artefactos de `Semana3/outputs/` y `Semana3/figures/`. No modifica las evidencias históricas de Semana 1 o Semana 2 ni el informe final.
